# Algo Studio

**Algo Studio** is an academic project designed to help students understand algorithms through interactive visualization.

Currently, the project allows users to **visualize sorting algorithms step by step**, making it easier to understand how different sorting techniques work.

## 🚀 Live Demo

[**Try Algo Studio →**](https://abeer609.github.io/algo-studio/bubble_sort.html)

## ✨ Features

* 📊 Interactive sorting algorithm visualization
* 🔄 Step-by-step execution
* 📈 Visual representation of array operations
* 🎓 Built as an academic project
* 🚀 More algorithms can be added in the future

## 🧩 Currently Supported

* Bubble Sort
* Selection Sort

## 🎯 Goal

The goal of Algo Studio is to make learning algorithms more **visual, interactive, and easy to understand** rather than relying only on theoretical explanations.
